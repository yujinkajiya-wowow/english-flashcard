# デイリーフラッシュ

毎日15語ずつ新しい英単語を出し、エビングハウスの忘却曲線（1日後・1週間後・1ヶ月後）で復習させる単語帳。フレームワークなしの HTML / CSS / JS。

## 起動

```sh
python3 -m http.server 8000   # → http://localhost:8000
```

`file://` で直接開くと Free Dictionary API の fetch がブラウザによって弾かれるので、ローカルサーバー経由で開く。

## ホーム

- 左のバー：アイコンだけのバー。カーソルを置いたまま少し待つ（タッチは長押し）と広がってラベルが出る。いちばん下が設定
- 日付、時刻（19:55 は「1955」）、今日のひとこと（Gemini で1日1回作って保存。キーが無いときは用意した文から日付で選ぶ）、連続記録
- 設定（効果音・スワイプ方向・API キー・JSON 書き出し）は単語一覧から設定画面に移した

## 単語の追加

- 英単語を打って Enter → 日本語訳を打って Enter で1語追加され、そのまま次の単語を入力できる
- 日本語訳が空のまま Backspace で英単語欄に戻る。日本語入力の変換確定の Enter では進まない
- 「英単語,日本語」の行を英単語欄に貼り付けると、まとめて追加する（区切りはカンマ・読点・タブ）
- 追加した行もそのまま直せる（直した時点で単語データに反映。英単語を直すと発音記号を取り直す）
- 単語は Enter の時点で保存されている。「保存」を押すと、入力途中の行があれば追加してから画面をまっさらにする

## アプリとして入れる（PWA）

- Mac の Chrome で GitHub Pages のページを開き、アドレスバー右の「インストール」アイコンを押すと、Dock から開ける専用ウィンドウのアプリになる
- iPhone は Safari の共有ボタン →「ホーム画面に追加」
- `sw.js` がファイルを保存しておくので、オフラインでも開ける（AI解説・採点・今日のひとことの生成はネットが必要）。オンラインのときは毎回最新版を読みに行く
- アイコンの元は `icons/icon.svg`（通常）と `icons/icon-maskable.svg`（切り抜かれる前提の全面版）

## 復習のルール

- 初めて出題した日を0日目として、1日後 → 1週間後（7日目）→ 1ヶ月後（30日目）の3回復習する
- 「覚えている」で次の復習日へ。「覚えていない」なら翌日に出し、そこから1日後・1週間後・1ヶ月後をやり直す
- 1ヶ月後の復習をクリアしたら「習得済み」で、ふだんの出題から外れる
- 判定に使うのは、その日1回目の回答だけ。結果画面の「もう一度学習する」は今日答えた単語のおさらいで、スケジュールや正答率は変えない
- テストは、今日フラッシュカードで答えた単語だけから出題する

## デスクトップ版（Mac アプリ・トラックパッドが振動する）

`src-tauri/` が Tauri のデスクトップ版。中身は Web 版と同じファイルで、トラックパッドの振動（`NSHapticFeedbackManager`）だけを Rust 側で受け持つ。

- main にマージすると GitHub Actions（`.github/workflows/desktop.yml`）が Mac 上でアプリを作り、[Releases の desktop-latest](../../releases/tag/desktop-latest) に `DailyFlash_*.dmg` を置く
- Apple の署名はしていない（アドホック署名のみ）ので、初回は「システム設定 → プライバシーとセキュリティ」の「このまま開く」で起動する
- 振動は、引っぱっている途中から「コッ…コッ…ココココ」とだんだん間隔が詰まり、確定ラインを越えた瞬間に強めの2回。Mac の振動は強さを変えられないので、間隔と種類（弱→普通→強）で強くなっていく感じを出している。指が触れている間しか感じないため、離した後には鳴らさない
- データはブラウザ版とは別に保存される。ブラウザ版の設定画面で「JSONを書き出す」→ デスクトップ版の設定画面で「JSONを読み込む」で移す
- 手元で作るとき：Rust と Xcode のコマンドラインツールを入れて `./scripts/prepare-dist.sh && npx @tauri-apps/cli@2.12.1 build`

## 操作

- クリック / スペース：裏返す
- トラックパッドの2本指スワイプ（左＝覚えている、右＝覚えていない）。大きくスワイプして、端が色づいた状態で指を離すと確定。足りなければ中央に戻る
  - 動かし始めは敏感で、端に近づくほど重くなる。調整は `js/swipe.js` 冒頭の定数
- ← / → キー：即確定
- 初めて出てくる単語は、表面の英単語がグレーで出る。キーボードで打つと打った文字から黒くなり、打ち終わると自動で裏返る（英数字以外は打たなくていい。Backspace で1文字戻る）。初出題の日は判定しないので、どちらにスワイプしても紫で、正答率にも入らない
- `?date=2026-10-20` を URL に付けるとその日付として動く（スケジュールの確認用）

## テスト

ナビの「テスト」から、今日の単語（今日答えた復習・新規＋まだ残っている分。まだ何もしていなければ今日の出題予定）を全部1回ずつ出題する。

- 単語記述：日本語訳を見て英単語を入力（完全一致。大文字小文字と前後の空白は無視）
- 単語選択：4択。上に1つ・下に3つの、矢印キーと同じ並び（クリック or ↑ ← ↓ →）
- 文章翻訳：AI解説の例文（日本語）を英訳し、Gemini が採点する。スペルミスは直して（直した文字は薄く塗る）許し、意味の単位で違えば不正解。一言コメント付き。採点後は右下の「AI解説」から、その問題についてチャットできる。Gemini の API キーが無いときは出題しない
- 正解はカードが左へ、不正解は右へ飛ぶ。不正解のときは正解を見せてから飛ぶ。文章翻訳だけは、コメントを読めるように Enter を押してから飛ぶ
- 文章翻訳で不正解だったときは「保留」になる。解答を直して Enter で採点し直せる。直さずに Enter を押すと不正解で確定して次へ。正答率に入るのは1回目で正解したときだけで、直して正解したものは結果画面で別に数える
- テストの結果は復習スケジュールには反映しない
- 結果画面：スコア（正答率と間違えた単語）、形式別の正答率（同心円）、ベストスコアと前回比較・最近7回のスコア。テストの記録は localStorage の `df.tests` に残る

## AI解説

カード裏面の「AI解説」から、品詞・意味・注意点・例文を生成し、追加で質問もできる（Gemini API の無料枠）。

- API キーは [Google AI Studio](https://aistudio.google.com/apikey) で作り、単語一覧の右上「Gemini APIキー」に入れる。キーはこのブラウザの localStorage にだけ保存され、JSON 書き出しにも含まれない
- モデルは `gemini-flash-lite-latest`（無料枠の回数が多い）。変えるなら `js/ai.js` の `MODEL`
- 無料枠では、送った内容が Google のサービス改善に使われることがある。単語と質問しか送らないので気にしなくていいが、個人情報は質問に書かないこと
- サーバーが無いので、ブラウザから直接 API を呼んでいる。自分専用のアプリとして使う前提
- 生成した解説は単語データに保存するので、同じ単語で何度も API を呼ばない。単語一覧で英単語か訳を直すと作り直す

## 構成

| ファイル | 役割 |
|---|---|
| `js/storage.js` | localStorage の読み書きはここだけ。DB に移すときはここを差し替える |
| `js/scheduler.js` | 復習間隔・出題リストの計算 |
| `js/swipe.js` | wheel(deltaX) / ドラッグでのカード操作、離したら確定 |
| `js/haptic.js` | `haptic()`。Web では効果音＋揺れ、`navigator.vibrate` 対応端末は振動、Tauri/Electron ではネイティブを呼ぶ |
| `js/ipa.js` | 発音記号の取得と保存 |
| `js/ai.js` | Gemini API の呼び出し（解説の生成・追加の質問） |
| `js/explain.js` | AI解説パネルの表示 |
| `js/test.js` | テスト（単語記述・単語選択・文章翻訳） |
| `js/app.js` | 画面（フラッシュ / 追加 / 一覧） |

## 仕様からの補足

- 忘却曲線の0日目は「登録した日」ではなく「初めて出題された日」。1日に20語登録しても新規枠は15なので、溢れた分は翌日以降に回り、その日から数える
- 初出題の日の判定は stage を動かさない（どっちでも翌日に1日目の復習）
- ブラウザから Mac のトラックパッドを振動させる API は無い
